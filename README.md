
# Python Code Tracer

An online Python execution and tracing application.

## Features

- Python code editor
- Line-by-line execution history
- Variable tracking
- SQLite support
- Pandas support
- NumPy support
- Matplotlib visualization
- Program output and error reporting

## Installation

pip install -r requirements.txt

## Run locally

streamlit run app.py

## Deployment

Upload the project to GitHub and deploy through Streamlit Community Cloud.
